# FindMyCar Roadmap

## Introduction

Cette roadmap décrit l'ordre de développement des fonctionnalités de FindMyCar.

Contrairement à `MODULES.md`, qui présente les capacités du produit, ce document décrit la stratégie de développement et les grandes étapes du projet.

La roadmap est un document vivant.

Elle évoluera en fonction :

- des retours utilisateurs ;
- des opportunités business ;
- des partenariats ;
- des contraintes techniques.

---

# Version 1 — MVP

## Objectif

Construire un moteur capable d'aider un utilisateur à trouver un véhicule pertinent.

### Sprint 1

Statut : ✅

Objectif :

Créer le cœur métier.

Fonctionnalités :

- Search Engine
- Compatibility Engine
- Opportunity Engine
- Scoring Engine

---

### Sprint 2

Statut : 🚧

Objectif :

Construire une architecture ouverte aux marketplaces.

Fonctionnalités :

- Marketplace Provider
- Listing Repository
- Provider Factory
- Fake Provider
- Étude des marketplaces
- Documentation produit
- Vision stratégique

---

### Sprint 3

Statut : 📋

Objectif :

Premier provider réel.

Fonctionnalités prévues :

- AutoScout24
- VIN Provider
- Reliability Provider
- Description Analyzer
- Premier pipeline complet

---

# Version 2

Objectif :

Transformer FindMyCar en véritable assistant automobile.

Modules prévus :

- Comptes utilisateurs
- Favoris
- Alertes
- URL Import
- Manual Import
- Browser Extension
- Recommendation Engine
- Risk Analyzer
- Image Analyzer
- Price Estimation
- Public API

---

# Version 3

Objectif :

Développer l'écosystème FindMyCar.

Modules prévus :

- Dealer Portal
- Professional Dashboard

# Principes

La roadmap n'est pas figée.

Les priorités pourront évoluer.

Cependant, chaque évolution devra respecter :

- PRODUCT_VISION.md
- BUSINESS_VISION.md
- TECHNICAL_VISION.md

La qualité primera toujours sur la rapidité.

Nous préférons livrer moins de fonctionnalités mais les rendre excellentes.

# Conclusion

Cette roadmap représente la direction actuelle de FindMyCar.

Elle ne constitue pas un engagement définitif mais un guide permettant de conserver une vision cohérente du développement du produit sur plusieurs années.
