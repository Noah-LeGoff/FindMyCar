# Principes

Chaque partenariat devra respecter les principes définis dans :

- PRODUCT_VISION.md
- BUSINESS_VISION.md
- TECHNICAL_VISION.md

Avant toute collaboration, nous répondrons systématiquement à trois questions :

- Quelle valeur pour l'utilisateur ?
- Quelle valeur pour le partenaire ?
- Quelle valeur pour FindMyCar ?

Si l'une de ces réponses est insuffisante, le partenariat devra être repensé.

---

# Conclusion

Les partenariats constituent l'un des piliers du développement de FindMyCar.

Notre objectif est de construire un écosystème durable, fondé sur la confiance, la transparence et la création de valeur pour l'ensemble des acteurs.

Ce document sera mis à jour à mesure que de nouveaux partenaires seront identifiés, contactés ou intégrés.
