# Principes de documentation

Chaque document doit respecter les règles suivantes :

- un objectif clairement défini ;
- une responsabilité unique ;
- un nom explicite ;
- une mise à jour régulière ;
- une cohérence avec les autres documents.

La documentation doit évoluer au même rythme que le code.

---

# Philosophie

La documentation n'est pas un livrable secondaire.

Elle fait partie intégrante de FindMyCar.

Chaque décision importante doit être documentée afin de préserver la compréhension du projet, faciliter son évolution et permettre à de nouveaux contributeurs de s'y intégrer rapidement.

---

# Conclusion

L'objectif de cette documentation est de rendre FindMyCar compréhensible, maintenable et évolutif.

Quel que soit le stade de développement du projet, chaque décision importante doit pouvoir être retrouvée, comprise et justifiée grâce aux documents référencés dans cet index.
